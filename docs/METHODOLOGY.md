# Предметная методология

## Космическая погода

Используются опубликованные NOAA/USAF суточные вероятности `S1 or greater` либо `Proton` в процентах. Это **внешний прогноз**, а не наблюдение на орбите МКС и не наша прогностическая модель. Собственный расчёт только пересекает сутки прогноза с окном ВКД, проверяет доступность на cutoff и применяет экспериментальный порог внимания 30%. Источники и временной смысл сохраняются в каждом event. `Proton` из RSGA и `S1+` из 3-Day Forecast представлены разными `quantity` и не усредняются. Два показателя одного физического механизма не считаются двумя факторами. Трёхчасовые строки planetary Kp из 3-Day Forecast сохраняются как `external_forecast_context`: они показывают ожидаемую геомагнитную динамику, но без отдельной физической модели не переводятся в дозу/опасность ВКД и не меняют S1-сравнение.

Связь с ВКД: солнечные энергичные частицы относятся к внешней радиационной обстановке, но GOES наблюдает геостационарную область, а суточная вероятность не описывает локальную дозу за конкретный выход. Порог 30% — исследовательская настройка визуального внимания, не норматив. Точное время начала события из суточного прогноза не выводится. Отсутствие предупреждения/продукта не доказывает отсутствие воздействия.

## Сближения с каталогизированными объектами

В current mode используется таблица CelesTrak SOCRATES для ISS. Источник даёт время наиболее близкого сближения (TCA), минимальную рассчитанную дистанцию и относительную скорость для экранного интервала примерно на следующие семь суток. Код отдельно хранит `source_as_of`, границы прогнозного интервала и проверяет, что свежий/кешированный выпуск действительно покрывает не менее следующих шести часов. Это и есть наиболее прямое выполнение требования задачи о прогнозе минимум на шесть часов; речь идёт о горизонте прогноза, а не о шестичасовом шаге.

SOCRATES screening в 5 км используется только как граница того, какие сближения источник сообщает/какие кандидаты историческая реконструкция ищет. Это не эксплуатационный предел ВКД. Минимальная дистанция рассматривается как геометрический индикатор близости станции и каталогизированного объекта. `Max Probability`, если он присутствует в SOCRATES, не является вероятностью попадания объекта в человека; собственной collision probability без ковариаций система не вычисляет.

Для 01.05–30.06.2024 используется зафиксированная историческая TLE-выборка. На начало каждого окна выбирается один снимок элементов МКС и каждого кандидата и держится неизменным по всему окну; возможное переключение на новый TLE внутри окна показывается как sensitivity diagnostic. По грубой сетке выполняется консервативный поиск кандидатов, затем минимум уточняется. Известные пристыкованные/ассоциированные аппараты исключаются только по source-backed time-bounded списку; устойчивое близкое движение неизвестного объекта помечается как неоднозначное, а не как независимое опасное сближение.

Возраст выбранных элементов показывается в результате: возраст ISS, распределение p50/p90/p99 по кандидатам и возраст TLE каждого обнаруженного прохода в момент TCA. При проверке 28.05.2024 12:00 UTC p99 возраста кандидатных элементов около 471 часа, максимум около 710 часов; у показанного прохода объектный TLE имел возраст около 16 часов. Числовой предел пригодности здесь не введён без калибровки ошибки распространения для этого набора. Эти данные усиливают статус реконструкции и запрещают читать дистанцию как точную фактическую дистанцию 2024 года.

Историческая ветка **не является strict replay**: TLE epoch не равен времени публикации, point-in-time полнота каталога неизвестна, ковариаций нет. Поэтому исторический фактор сближений имеет `decision_eligible=false`. Если реконструкция не нашла проход внутри 5 км, это не превращается в благоприятное сравнимое значение.

## Освещённость как дополнительное условие плана

SGP4-траектория также позволяет оценить попадание МКС в приближённую цилиндрическую тень Земли. Это не второй внешний риск-механизм. Освещённость получает `role="plan_constraint"` и участвует в сравнении только если аналитик явно отметил необходимость прямого солнечного света. В strict replay историческая освещённость также исключается из решения из-за неизвестного publication time орбитальных элементов.

## Оценка и сравнение

Для каждого фактора хранится собственное состояние, покрытие, свежесть, evidence, правило, ограничения и признак пригодности для решения. `insufficient` у decision-eligible фактора блокирует рекомендацию. Устаревший текущий кеш сохраняется для просмотра, но не объявляется полноценным свежим прогнозом. Сравнение по Парето: явное улучшение одного допустимого фактора без ухудшения других. Если на фронте остаются разные компромиссные окна — `tradeoff`; если различий нет — `equivalent`; произвольный суммарный вес не вводится. Сокращение длительности через новый запрос меняет план; сравнение проводится только между окнами одной длительности.

## Где заканчивается интерпретация

В current mode SOCRATES является вторым механизмом и предоставляет прогнозную геометрию. Для 2024 года не найден проверяемый публичный архив исторических выпусков SOCRATES с доказанным временем их доступности, поэтому текущую таблицу нельзя переносить назад во времени. Историческая TLE-реконструкция полезна для проверки геометрических сценариев, но не подменяет архивное предупреждение. Аналогично, суточная S1/Proton probability не является вероятностью воздействия в конкретном окне ВКД. Система сравнивает только те величины, смысл и provenance которых можно защитить отдельно.
