# Воспроизводимый эксперимент

Команда: `python scripts/research.py` при `PYTHONPATH` равном корню проекта. Она выполняет обычный расчет `run`, сохраняет полные JSON с provenance и только затем читает сохранённый каталог NOAA SEP для проверки. Исходные записи архивированы в `data/noaa/`, дата cutoff записана в каждом JSON. Baseline использует только последнюю суточную вероятность протонного события и переносит её на все окна одинаково, без траектории и временного пересечения.

* **Выраженное событие:** запрос 10.05.2024 06:00 UTC, cutoff 00:00. Доступный на cutoff выпуск RSGA 09.05 22:00 дал 50% вероятности. Проверочный каталог NOAA позднее зафиксировал начало 10.05 13:35 UTC, максимум 208 pfu в 17:45 UTC. Это проверка наличия события **в течение суток**, не доза на МКС и не факт воздействия в каждой из трех ВКД.
* **Контроль для этого механизма:** 02.05.2024 06:00 UTC, cutoff 00:00, вероятность 10%. В выбранном каталоге SEP нет начала S1 в этот день. Это контроль **протонного события**, хотя другие геомагнитные явления могли происходить.
* **Польза временной привязки второго фактора:** 05.05.2024 01:00 UTC, одночасовые окна, cutoff 04.05 23:00. Baseline видит одинаковые 15% для всех окон. Полный прототип рассчитывает 0, 15 и 25 минут земной тени и предпочитает первое окно при требовании прямого солнечного света. Это условный вывод с реконструированной орбитой.

Для двух проверочных суток Brier score вероятности наступления протонного события равен 0.25 (событие) и 0.01 (контроль), среднее 0.13 **для baseline и погодной линии полной системы одинаково**: используется один внешний прогноз. Две точки не дают статистически значимой оценки качества. Нельзя утверждать, что полная система лучше предсказывает солнечную погоду. Дополнительная информация полной системы — связь факторов и ограничений с окном. Суточный прогноз не позволяет проверить точность времени наступления или число ложных предупреждений по часам. Сохраненные файлы `research_results/{event,control,window_demo}.json` и `summary.json` содержат значения и исходные записи.
