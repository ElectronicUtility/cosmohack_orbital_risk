# GitHub Pages

Демо: https://krotkoves.github.io/cosmohack_orbital_risk/

Пять сохранённых сценариев, сравнение окон, 3D, первоисточники и HTML/JSON/ZIP-экспорт доступны без Python-сервера. Новые расчёты и обновление текущих источников требуют FastAPI: запустите приложение по README. Публичный URL полного сервиса пока не развёрнут.

## Сборка

```sh
python -m pip install -r requirements.txt
python scripts/build_pages.py
python -m http.server 8002 --directory dist
```

Открыть http://localhost:8002/. Каталог `dist` должен быть пустым перед сборкой. Скрипт читает проверенные снимки из `research_results`, проверяет хеши исходников при упаковке ZIP и не обращается к текущим источникам. CI также выполняет сборку.

Для публикации скопируйте содержимое `dist` в корень ветки `gh-pages` и отправьте обычный коммит. В Settings → Pages выбран источник `gh-pages`, каталог `/`. Не копируйте локальную SQLite или `.env`. В текущем развёртывании используется fork `krotkoves/cosmohack_orbital_risk`: права администратора исходного репозитория недоступны.

Разделы используют `?page=archive`, `?page=sources`, `?page=method`: прямые ссылки и обновление страницы работают без серверного перенаправления. Файлы текстур, модели и декодера размещены вместе с приложением.

Ограничения статического режима доступны в подсказке «Прототип». Слайды не включаются в поставку.
