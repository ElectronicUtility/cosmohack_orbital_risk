## Проектные рекомендации и дополнительные функции

Python/FastAPI/Pydantic/httpx/SQLite и SGP4 выбраны после отсутствия существующего кода; официальная постановка стек не предписывает. Вторым физическим механизмом выбраны сближения: current использует SOCRATES, а исторический режим выполняет TLE-реконструкцию с явным запретом выдавать её за strict point-in-time предупреждение. Освещённость оставлена как дополнительное условие плана и не считается вторым внешним риск-механизмом. UI сделан на обычном JavaScript без отдельной сборки; React был рекомендацией. Дополнительные 3D-глобус, ML, уведомления, регистрация и автоматический глобальный поиск окон не реализованы.
