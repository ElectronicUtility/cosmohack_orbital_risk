Пробы сохранялись до разработки ядра. Для всех источников без опубликованных в доступной документации квот предел запросов отмечен как неизвестный. Наличие `Last-Modified` HTTP или орбитальной эпохи не приравнивается к исходному времени публикации. Второй механизм выбран после проверки SOCRATES, согласно разрешению официальной постановки. Источники не считаются независимыми, если перепечатывают одно и то же измерение.
