# Состояние версии 0.6.0

Upstream `ee820e1` включён, включая компактные подсказки из PR #5. После слияния исправлены проверки возраста источников и покрытия следующих шести часов. Активный current-план пересчитывается каждые пять минут; сохранённые снимки не меняются. Причины недостаточности различают устаревший выпуск, отключение, неполную сводку и несовместимые суточные значения.

HTML из API, браузера и ZIP использует один renderer. Автономный отчёт проверен в браузере без сети, снимок совпадает с JSON. ZIP проверяет исходные байты по SHA-256.

Проверено 76 Python-тестов и 18 JavaScript-тестов. В изолированном браузере проверены автоматический пересчёт и остановка таймера. Docker собирается и запускается без root, healthcheck проходит; новый расчёт и ZIP создаются, запись сохраняется после перезапуска контейнера.

Исследование: 108 окон освещения, 36 окон с независимым солнечным расчётом ERFA и 244 проверки солнечного направления. Погодный эксперимент: 61 день, 60 размеченных по NOAA SGAS; 3 обнаружения, 1 пропуск и 7 ложных тревог при фиксированном пороге 30%. Методика и ограничения: `EXPERIMENT.md`.

Живая проверка источников 19.09.2026 около 19:15 UTC: NOAA и TLE актуальны, SOCRATES от 18.09 22:16:38 UTC имеет возраст около 21 часа и помечен устаревшим при пределе 12 часов. Порог не ослаблялся. Снимок: `research_results/current_health_20260919.json`.

Публичное демо: https://krotkoves.github.io/cosmohack_orbital_risk/. Pages содержит пять сохранённых сценариев, 3D, объяснения и переносимые экспорты. Новый расчёт и текущие источники требуют FastAPI; публичный backend пока отсутствует. Инструкция: `PAGES.md`. Историческая публикация TLE и полнота каталога не доказаны; геометрия остаётся реконструкцией. Проверки не подтверждают дозу, вероятность повреждения скафандра или эксплуатационный допуск ВКД. Полные баллы жюри не гарантируются. Новые слайды в версии 0.6.0 не создавались.
