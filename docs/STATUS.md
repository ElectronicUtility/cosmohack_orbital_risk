# Состояние исследовательского прототипа

Срез алгоритма `0.5.0`. Репозиторий содержит исходный код, фиксированные исторические данные с provenance, исследовательские сценарии, тесты и GitHub Actions для проверки на Python 3.12.

| Часть | Состояние | Граница вывода |
|---|---|---|
| Current: NOAA, ISS TLE, SOCRATES | Работает при доступности внешних сервисов | Сближение относится к МКС и каталогизированному объекту, не к вероятности поражения космонавта |
| Historical: 01.05–30.06.2024 | Погодные выпуски и TLE-реконструкция включены в `data/` | Доступность исторических TLE на момент решения не доказана |
| Strict replay | Cutoff фильтрует погодные выпуски по `Issued`, ретроспективному `Last-Modified` и SHA-256 до анализа | Строгость относится к погодной линии; поздние SEP-наблюдения читаются только после расчёта |
| Сравнение окон | Равная длительность, сравнение по отдельным допустимым величинам, Pareto outcomes | Разные NOAA quantities не сравниваются как одинаковые проценты; historical conjunctions и lighting не меняют strict-replay решение |
| Исторические сближения | Локальная зафиксированная TLE-выборка, численный поиск TCA и sensitivity diagnostics | Нет ковариаций, point-in-time полноты каталога и проверенных времён публикации отдельных элементов |
| Сохранение и экспорт | SQLite, JSON, HTML с evidence | База создаётся локально; ZIP содержит использованные исходные байты с проверкой SHA-256; при отсутствии байтов возвращается ошибка |
| Исследование | Baseline, event/control, воспроизводимые файлы | Полная разметка целевого события для Brier score отсутствует; преимущество в качестве прогноза не заявляется |

Подготовлены четыре слайда `/static/briefing.html` и четырёхминутный маршрут `DEMO.md`. Публичное развёртывание и живое выступление не проверены. UI переработан в интерактивный пульт ВКД: орбитальная схема, связанные окна и временные дорожки, доказательства, сохранённые примеры, HTML/JSON-экспорт и режим показа. Подробности и проверки — в `UI_DESIGN.md`. Для расширения строгого исторического сравнения на сближения требуется архив выпусков с доказанным временем публикации, полным каталогом и данными об неопределённости орбит. Эти ограничения нельзя устранить изменением порога или интерфейса.

Живой smoke test 18.09.2026 около 21:32 UTC получил NOAA, ISS TLE и SOCRATES. Таблица SOCRATES содержала `Data current as of 17.09.2026 22:14:23 UTC`, то есть возраст источника около 23,3 часа при инженерном пределе 12 часов. Current comparison вернул `insufficient` по сближениям. Это ожидаемая защита от устаревших данных; текущая работоспособность решения зависит от обновления SOCRATES.


В версии 0.5.0 сравнение вынесено над орбитой, все погодные значения и минуты тени видны одновременно, проигрывающие варианты помечены. Форма принимает русскую дату в UTC и имя задачи; история различает задачи и итоги. Страница источников показывает состояние текущих подключений и ручное обновление. Полноэкранная сцена сохраняет заключение, рассчитанная тень отмечена на траектории.

Чистая установка выполнена на Windows с Python 3.12. Проверка освещения: 36 планов, 108 окон, средняя абсолютная разница между сетками 5 и 1 мин — 0,0029 мин, максимум — 0,0625 мин. Это численная сходимость одной приближённой модели, а не независимая оценка её физической точности. Отдельно проверен опубликованный контрольный вектор SGP4. Карта исправлений: `JURY_FIXES.md`.

Живое обновление 19.09.2026 в 18:47 UTC получило все три источника. NOAA и TLE актуальны по проверке кеша; выпуск SOCRATES от 18.09 22:16 UTC превышает предел 12 часов. Снимок состояния: `research_results/current_health_20260919.json`. Отображение устаревания сохранено, порог ради демонстрации не ослаблен.
