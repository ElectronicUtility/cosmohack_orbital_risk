# Пульт ВКД: интерфейс и проверка

## Пользовательский маршрут

Первый экран открывает **сохранённый исследовательский пример** «Свет и тень». Это явно подписанный архивный результат, а не имитация текущей обстановки. Три сценария читаются из `research_results/` через allowlisted read-only endpoint `/api/examples/{name}`. Просмотр примера не создаёт записи в базе и не обращается к внешним источникам.

1. Исследовать готовый сценарий или задать свой план.
2. Выбрать окно A/B/C: сцена, время, шкала и карточки связаны одним состоянием.
3. Пройти по рассчитанным точкам орбиты ползунком/стрелками либо запустить воспроизведение.
4. Открыть фактор из временной шкалы, проверить единицы, время и источник.
5. Изменить параметры и пересчитать. До успешного ответа сохраняется прежний результат с явным предупреждением.
6. Скачать HTML-заключение или JSON именно показанного расчёта, скопировать ссылку.

При изменении формы вывод не пересчитывается в браузере. Все рекомендации приходят из существующего `/api/analyze`. Состояния `preferred`, `equivalent`, `insufficient` и компромисс не превращаются в общую шкалу «безопасности». Сбои, неполнота и старые источники сохраняют исходную семантику backend.

## Визуальная система

Графит, тёплый светлый текст, лаймовый акцент выбора, янтарный сигнал внимания. Неизвестность — отдельная штриховка и текст, без зелёного статуса. Крупная орбитальная схема задаёт предметный контекст; сравнительные значения и доказательства остаются обычным HTML.

| Слой | Данные и смысл | Рендер / взаимодействие | Проверка |
|---|---|---|---|
| Орбитальная сцена | `position_teme_km`, единый масштаб с радиусом Земли 6378.137 км | Один Canvas2D; ортографическая проекция, вращение мышью и кнопками, выбор точки | Положение из API; подпись TEME/схема; нет выдуманных географических координат |
| Временные дорожки | Интервалы погодного прогноза, TCA, тень из evidence | HTML, общая временная шкала выбранного окна, курсор синхронен точке орбиты | Обрезка по границам окна, переход через UTC-полночь, пробелы и неполнота |
| Карточки | Отдельные показатели факторов для равной длительности | HTML-кнопки с `aria-pressed`, A/B/C над сценой и в карточках | 0/10/25 минут тени не изменяют strict replay; 15% остаётся суточной величиной |
| Cutoff | Последний использованный погодный выпуск и момент отсечения | Схематическая последовательность, без притворной пропорциональной шкалы времени | Поздние сведения не объявляются доступными; реконструкция подписана |
| Доказательства | Исходный фактор, записи, ограничения и хеши | Нативный модальный dialog, Escape/возврат фокуса, прогрессивное раскрытие | Полные сведения сохранены; ссылки только HTTP(S), текст экранирован |

Canvas выбран для вращаемой схемы с большим количеством повторяющихся линий; SVG был бы возможен, но потребовал бы множества изменяемых узлов. Семантические подписи, числовые значения и управление оставлены в DOM. Это лёгкая проекция данных, не отдельный физический симулятор. Сетка инерциальная, не географическая; размер маркера МКС увеличен для видимости. Светотень оформления сферы не представляет измеренное освещение. Условия освещения читаются из расчётных интервалов ниже.

Одна сцена, DPR ограничен 2; перерисовка только при resize, изменении точки/окна и вращении. Воспроизведение выключено по умолчанию, меняет дискретную точку раз в 800 мс и останавливается при уходе со вкладки. Нет постоянного фонового рендера, внешних текстур, CDN, загрузки шрифтов или production npm-зависимостей. CSS/View Transitions — необязательное улучшение; при reduced motion переходы отключаются. Весь сайт обслуживает прежний FastAPI.

## Состояние, доступность, мобильная версия

- URL: `?example=window_demo&window=2` или `?analysis=<id>&window=0`. Перезагрузка и назад/вперёд восстанавливают результат. Сохранённый id существует в базе именно этого сервера; localhost-ссылка не открывает сервис на другом компьютере.
- История и текущая обстановка не смешиваются. Момент формы интерпретируется явно в UTC, независимо от часового пояса браузера.
- Неуспешный запрос не очищает последний результат. Изменённая форма не выдаёт старое заключение за новое; есть восстановление исходных параметров.
- Range и кнопки обеспечивают альтернативу drag; touch сохраняет вертикальный скролл. На узком экране карточки и панели перестраиваются в одну колонку. Модальное окно занимает ширину экрана.
- Есть skip-link, текстовые значения, фокус, aria-подписи, статусы загрузки и ошибок, reduced-motion fallback. Полная экспертная accessibility-аудитория не привлекалась.
- Режим показа скрывает форму и служебную навигацию; это композиция для демонстрации, не отдельный расчётный режим.
- HTML-отчёт содержит таблицы, параметры, источник каждого фактора и полный сериализованный расчёт. JSON — оригинальный объект без изменения научных данных.

## Изученные приёмы и первоисточники

Проверено 19.09.2026. Эти подходы не объявляются изобретёнными командой: отличие продукта создаёт их применение к конкретному рабочему сценарию.

- [NASA Eyes](https://science.nasa.gov/eyes/): пространственная ориентация и исследование по времени. Принцип связанности применён к собственной SGP4-геометрии; оформление NASA не копировалось.
- [NN/g: Design Guidelines for Complex Applications](https://www.nngroup.com/articles/complex-application-design/): контекст задачи и раскрытие сложности по мере необходимости. Сводка → фактор → доказательство → исходная структура.
- [Chrome: same-document View Transitions](https://developer.chrome.com/docs/web-platform/view-transitions/same-document): плавное переключение согласованных состояний с fallback без API. Переходы короткие и не являются зависимостью расчёта.

Локально применены специализированные подходы к оперативным интерфейсам и Canvas2D. Аналитическая задача — сравнение вариантов и исследование условий во времени, а не мониторинг непрерывного потока.

## Проверки

```sh
python -m pytest -q
npm test
```

Node нужен только для дополнительных тестов чистых presentation helpers. Для запуска сайта достаточно Python-зависимостей из README. Тесты UI проверяют сохранение смысла replay, клиппинг интервалов, UTC, инвалидирование изменённого плана, неполноту, границы тени, экранирование и параметры URL. Тесты API проверяют отсутствие побочного сохранения примеров, совпадение научных данных и allowlist имён.

До сдачи проверить внешнюю доступность деплоя отдельно: локальный preview не является публичным сервисом. Текущие прогнозы по-прежнему зависят от доступности и свежести внешних источников. Переделка интерфейса не расширяет физическую модель или исторические гарантии.
