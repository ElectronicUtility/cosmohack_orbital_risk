# Рабочее пространство ВКД

Интерфейс разделён на четыре адресуемых раздела: планирование, расчёты, источники и методика. Дизайн и источники исследования: [UI_RESEARCH.md](UI_RESEARCH.md).

## Основной сценарий

1. Открыть сохранённый пример или создать расчёт в диалоге параметров.
2. Сравнить строки времени начала; выбор строки синхронно меняет орбиту, время и интервалы факторов. Воспроизведение и ползунок относятся к выбранному окну.
3. Открыть основания сравнения или конкретный фактор. Подробности, исключения и исходные записи раскрываются по запросу.
4. Скачать HTML-отчёт с показанным результатом либо JSON в разделе источников.

Палитра нейтральная: белый и холодный серый, синий для управления, оранжевый для МКС. Предупреждения получают отдельный цвет только по данным. Системная типографика, табличные цифры, компактные строки вместо повторяющихся карточек. Нет слогана, декоративной телеметрии, постоянной анимации или фоновой музыки.

## Данные и ограничения

Canvas показывает настоящие точки SGP4 в инерциальной системе TEME с общим масштабом радиуса Земли и траектории. Географической карты нет; размер маркера МКС увеличен. Светотень сферы — оформление объёма, не рассчитанная освещённость. Освещение читается по интервалам тени на временной шкале.

UI не меняет физическую модель, вероятность, пороги или правила выбора окна. Прогноз из прошлого использует только допустимые к отсечению сведения. Исключённые факторы явно помечаются; отсутствие событий не обозначает безопасность.

Сохранённые примеры доступны без создания записей в БД. Новые расчёты сохраняются сервером; список «Мои расчёты» хранит до 50 ссылок в localStorage этого браузера. Это не общий серверный реестр. Если браузерное хранилище недоступно, остаются серверный результат и его URL.

## Навигация и доступность

Прямые адреса `/planner`, `/archive`, `/sources`, `/method` поддерживают обновление страницы. Query-параметры сохраняют пример/идентификатор анализа и выбранное окно. Назад/вперёд восстанавливают контекст. Доступ к результату требует той же базы данных сервера.

Есть skip-link, видимый фокус, подписи кнопок, нативные диалоги с Escape, клавиатурное управление временем и кнопки поворота вместо обязательного drag. После выбора окна фокус сохраняется. На планшете навигация сворачивается до подписанных для скринридера иконок, на телефоне становится верхней панелью. Reduced motion отключает появление диалогов; полноэкранных crossfade-переходов нет.

Форма имеет явные единицы UTC. Изменённые параметры не подменяют отображаемый результат. Ошибка сохраняет предыдущий расчёт; его параметры можно восстановить.

## Проверки

`python -m pytest -q` и `npm test`. API-тест проверяет обновление каждого прямого маршрута и 404 для отсутствующего анализа. Остальные проверки охватывают replay, источники, UTC, интервалы и отчёты. В браузере проверены создание, сохранение, поиск, повторное открытие расчёта, страницы источников/методики, изменение окна и времени, диалоги и адаптивность.

Новых runtime-зависимостей нет. Приложение обслуживает FastAPI; внешние шрифты, CDN и сборка frontend не нужны. Это локально проверенный прототип, не публичный деплой.


## Изменения 0.5.0 после независимого аудита

Главный визуальный приоритет — решение с причиной; план и условия стоят перед геометрией. Компактные строки показывают погоду, минуты тени и роль каждого варианта одновременно. Повторяющиеся подписи удалены. Белый фон, графитовый текст, синий выбор и охра для тени сохраняют назначение цветов. Тень обозначается и цветом, и штриховкой на временной шкале.

В форме введены имя задачи и однозначные даты ДД.ММ.ГГГГ ЧЧ:ММ, UTC. История показывает имя и результат. В режиме защиты скрывается боковая навигация, укрупняются решение и числа; полноэкранная орбита сохраняет текст заключения. Два новых сохранённых случая рассчитаны обычным серверным алгоритмом. Страница методики отделяет внешние данные от собственного расчёта и показывает результаты проверок. ZIP доступен и для сохранённых примеров на чистой установке.
